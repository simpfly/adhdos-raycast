# ADHDOS Raycast 扩展

参考 Notion Snippets 的原生列表和表单交互，一个扩展内提供五个独立命令：

- **查看 Board**：最近最多 200 条，支持本地搜索正文和想法、详情预览、复制内容。
- **添加 Board**：表单输入文字或链接。
- **查看 BrainDump**：自动分页加载两个分区的未完成事项，支持搜索和子事项预览。
- **添加 BrainDump**：表单输入事项，选择主分区或次分区。
- **粘贴内容**：自动带入剪贴板文本，选择 Board 或 BrainDump，预览确认后添加。

列表内 `⌘N` 新增，`⌘R` 刷新。各命令可在 Raycast Settings 中单独绑定别名和快捷键。

## 配置

首次打开任一命令，在 Raycast 扩展设置填写 **ADHDOS API 密钥**。密钥通过 Raycast 密码偏好管理，不写入源代码；旧脚本的钥匙串密钥不会自动迁移。密钥来源：ADHDOS 设置 → MCP / API → API。需要有效 Pro 订阅、开启云同步并完成至少一次同步。

只调用 `https://adhdos.app/api/v1/board-items` 和 `/tasks`。日期文字按原文保存。暂不提供修改、完成或删除云端内容。

## 失败恢复

Board 新增必须按返回 ID 和原内容从云端读回确认，才显示成功；独立新增表单会展示读回的内容。该确认不代表桌面已完成同步。

新增前将原请求和编号保存到扩展 supportPath。网络结果不明时重新打开新增命令，会恢复内容并复用编号，避免重复新增。六天后或更换密钥后停止重试。可以先在 ADHDOS 核对结果，再在动作菜单选择“核对后清除重试记录”；清除本地记录不会删除云端数据。

并发保存用本机独占锁防止重复。如果进程异常退出留下锁，确认没有新增命令运行后，再清理扩展数据目录对应的 `board.lock` / `brain.lock`。待确认 JSON 应保留，用于重试。

## 开发

安装 Node.js 后在本目录执行 `npm install`，然后 `npm run dev` 导入本机 Raycast。本仓库包含所需链接工具，不依赖 ADHDOS 主仓库或其他扩展目录。

- `npm run build`：构建并检查类型。
- `npm run typecheck`：单独类型检查。
- `npm test`：模拟 API，验证分页、明确失败、超时幂等重试和并发保存；不读取个人数据。

停止开发监听后，已导入的本机扩展仍保留。不要将 API 密钥提交到仓库。

## 链接预览

新增纯 HTTP(S) 链接后会自动识别标题和封面，Bilibili 优先读取视频元数据，其他网页读取 Open Graph / Twitter / HTML 标题。查看 Board 时选中已有链接也会补全预览。右侧使用 Raycast 原生详情显示封面和网址，可打开链接或复制内容。解析最多等待 8 秒，失败保留网址且不影响已完成的云端保存。标题和封面地址缓存在本机扩展目录；当前 API 不支持写入标题字段，因此不向云端添加额外字段。

列表优先显示按 API 密钥隔离的本机缓存，并在后台刷新云端；可用 ⌘R 手动刷新。只有选中项渲染封面详情，快速移动选择时延后 150ms 解析。云端保存确认后立即展示结果，不等待外站标题和封面。

新增 Board 表单支持选择分区；从筛选后的列表新增会默认选中当前分区。分区选项来自缓存和最近 200 条云端卡片，空分区或较早分区可用“输入其他分区…”填写。提交通过 API 的 tab 字段保存，重试恢复原分区；读回确认同时检查内容与分区。

## 图片查看

Board 图片卡片和图片直链支持右侧原生预览、回车打开大图、重新加载及在浏览器打开原图。私有上传图片通过 `GET /board-items/:id/image` 获取 5 分钟有效的签名地址，服务端验证当前密钥、Pro 权益、卡片存在且文件属于同一用户；不接受任意存储路径。未登录或其他账户的文件不会获得签名地址。此版不包含卡片想法里的附件图片，当前列表 API 尚未返回这些附件。

图片预览缓存在本机扩展数据目录，按 API 密钥隔离：左侧使用 64px 缩略图，右侧使用最大 1280px 的静态 PNG 预览。后台两路批量加载、合并刷新；缓存保留 7 天，打开命令时清理过期及超过 200MB 的旧缓存。单张下载限制 15MB，动图预览为静态图。文字、链接、图片、视频和音频使用各自默认图标。

### 2026-10-17 功能对齐

- 添加 Board 改用 `tabsOnly=true` 分区元数据接口，包含空分区；失败时保留缓存选项和手动输入。
- 添加 Board 可同时填写收藏想法；沿用同一新增请求和持久化重试记录，读回检查包含想法。
- Board 预览、搜索和复制复用 `board-content.ts` 内容读取；复制包含追加想法，保留 Markdown，排除私有图片路径和内嵌图片字节。
- 新增字段使用 `strings.ts` 中英文资源；现有扩展文案仍为中文，本次未做完整语言迁移。

| 入口 | 原状 | 本次处理 / 范围 |
| --- | --- | --- |
| 独立添加 Board / 列表内添加 | 最近 200 条推断分区，无初始想法 | 共用 Create；读取分区元数据并支持初始想法 |

## 粘贴带子任务的内容

在 Raycast 搜索“粘贴内容”，选择 BrainDump，再继续查看识别预览。支持空格或 Tab 缩进、无序列表、编号列表，以及子任务的 `- [ ]` / `- [x]` 勾选状态。例如：

```text
1. 发布文章
  - [x] 整理资料
  - [ ] 检查排版
2. 买菜
  - 牛奶
```

普通标题下一行直接跟列表也会识别为子任务；同级列表项作为各自的主事项。子任务支持一级，更深的缩进归入同一主事项。添加 BrainDump 和粘贴内容复用同一解析与失败重试流程。

本次验证：50 项模拟测试通过，Raycast 构建与类型检查通过；未读取真实剪贴板或个人数据，未进行 Raycast 原生界面验收。
